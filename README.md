# Reference-based Burst Super-resolution (MM2024)


This page contains the official implementation of the following paper:
> **Reference-based Burst Super-resolution**<br>
> Seonggwan Ko, Yeong Jun Koh, Donghyeon Cho<br>
> ACM Multimedia (**MM**), 2024<br>

-----------
### Dataset
Click [here](https://drive.google.com/drive/folders/16__BYH8u4EQOefP-XpmULqWcXbYPdKRL) to download the dataset.  
We provide two datasets: the real RefBSR dataset and the synthetic RefBSR dataset.  
Our dataset loader is adapted from the [BurstSR dataset code](https://github.com/goutamgmb/deep-burst-sr), with the primary modification in the method used to load reference images.
